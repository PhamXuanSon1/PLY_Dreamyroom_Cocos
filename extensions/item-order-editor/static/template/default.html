Item Order Editor

Load selected node ↻ Xếp theo itemList Seat mode Bỏ hết Save
Chỉ hiện node có ItemController (Shadow, FX... giữ nguyên vị trí). Ô 1 = item đứng đầu trong Hierarchy. Kéo ô để đổi chỗ / chuyển cột; click 2 ô để swap. Thứ tự cuối = cột 1 từ trên xuống, rồi cột 2, ... Save ghi cả Hierarchy lẫn ItemManager.itemList (thứ tự spawn) và SeatHandler. Seat mode: click item cần khoá -> click các item phải ghép trước nó (🔒n = số item bắt buộc).
